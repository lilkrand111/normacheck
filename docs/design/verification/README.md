# Проверка реализации Forma — 28.10.2026

## Автоматические проверки

- `.venv/bin/python -m pytest tests -q`: **53 passed**.
  Осталось прежнее предупреждение Starlette о будущем переходе с httpx на httpx2.
- `node --test tests/frontend*.test.mjs`: **13 passed** (Node 24).
- Проверка синтаксиса app.js и `git diff --check`: без ошибок.

Тесты охватывают поиск, фильтры, выбор по исходному индексу, разные пустые
состояния, независимые операции, лимиты 429/503, отсутствие автоматических POST,
предварительное чтение перед исправлением, сохранение отметок при сбое и сброс
на новой версии, отказ localStorage, потерю доступа, CSRF и URL скачивания.
Настоящий app.js проверен в минимальном DOM: выбор файла не отправляет запрос,
уход на лендинг во время обработки не прерывает её и не позволяет ответу
переключить экран; переход по URL восстанавливает документ.
Python-тест проверяет доступность новых локальных CSS, JS, шрифтов и фонов
при сохранении CSP и закрытости серверных файлов.

## Реальный браузерный сценарий

Проверка через встроенный браузер Codex, с FastAPI на 127.0.0.1:8001.
Отдельное временное хранилище: `/private/tmp/nkprod-redesign/storage`.
DOCX с 12 абзацами сгенерирован во временной папке, рабочее `storage/` не использовалось.

1. Лендинг → выбор DOCX → отдельный запуск → отчёт: 53 замечания.
2. Категория F03, ручная отметка, скрытие: 11 подходящих из 53.
3. Поиск без совпадений показал отдельное пустое состояние; сброс вернул список.
4. Автоисправление завершилось новым отчётом: 12 оставшихся замечаний F02.
   Отметка исходной версии не перенеслась. Шрифты исправитель не меняет.
5. Исправленная копия скачалась с кириллическим именем из Content-Disposition.
6. Копирование фрагмента в буфер показало подтверждение.
7. Ручная отметка исправленного отчёта сохранилась после перезагрузки.
8. Назад/вперёд восстановили отчёт по UUID. Клавиатурный Tab показал видимый
   фокус; Enter открыл ссылку на границы проверки.
9. В журнале браузера не было ошибок и предупреждений приложения.

## Визуальная проверка

Сопоставлены экспортированные эталоны Forma из `../references/` и живой интерфейс.
