• Как это работает

Из DOCX — в проверенную копию.

01 / Загрузите DOCX

Выберите документ для проверки оформления по профилю СТП.

02 / Изучите замечания

Посмотрите ошибки, ручные проверки и рекомендации.

03 / Примените правки

Запустите автоисправление поддерживаемой части. Остальное — в Word.

04 / Получите копию

После повторной проверки скачайте исправленную копию.

Исходный файл не меняется. Оставшиеся замечания не мешают скачиванию после повторной проверки.

Два инструмента. Разные задачи.

Автоисправление меняет копию документа. Личная отметка помогает не потерять свой прогресс.

Автоисправление

Одна кнопка для всего документа. Только поддерживаемые нарушения исправляются автоматически — в отдельной копии.

Автоисправить документ ↗Далее — повторная проверка копии, затем скачивание.

Неподдерживаемые правки вы вносите в Word. Полное соответствие СТП не гарантируется.

Ручная проверка

Обратимая галочка «Исправлено» — только ваша отметка. Она не меняет DOCX и не уменьшает число замечаний.

• Важно знать

Наши самые
частые вопросы:

Границы проверки

Проверяем оформление по СТП, а не смысл и уникальность. Не все требования можно проверить или исправить автоматически.

Ограничения доступны отдельно и не смешиваются с ошибками в отчёте.

Что означают статусы замечаний?

Ошибка — найдено несоответствие. Ручная проверка — место нужно оценить самостоятельно. Рекомендация — полезное улучшение оформления.

Как найти нужное замечание в отчёте?

Поиск работает вместе с фильтрами категории и статуса. Настройки можно сбросить. Личные отметки учитываются отдельно от результатов.

Когда можно скачать исправленную копию?

После автоисправления и повторной проверки копии. Оставшиеся замечания не блокируют скачивание — их можно исправить в Word.

Если замечаний нет — документ соответствует СТП?

Это означает только: «В пределах выполненных проверок замечаний не найдено». Результат не заменяет ручную проверку требований.

Можно ли править документ прямо на сайте?

Нет. NormaCheck не редактор DOCX. Поддерживаемые правки применяются автоматически к копии, остальные вы вносите в Word.
